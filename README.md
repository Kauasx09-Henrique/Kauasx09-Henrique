## 👋 Sobre mim

Sou **Desenvolvedor Backend** com foco em **APIs, sistemas escaláveis e arquitetura de software**.  
Atualmente atuo como **Estagiário de TI no CENSIPAM** e sigo evoluindo em backend, banco de dados e integração entre sistemas.

Tenho experiência prática com:

- **Node.js, NestJS, Java, Spring Boot, PHP e PostgreSQL**
- Desenvolvimento de **APIs REST**
- Integração com banco de dados e regras de negócio
- Autenticação, segurança e organização de código
- Desenvolvimento mobile com **React Native**

Meu objetivo é crescer como engenheiro de software e construir soluções que sejam úteis, robustas e bem estruturadas.
